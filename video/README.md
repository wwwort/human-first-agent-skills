# 成片与配音

`human-first-execution-3min-draft.mp4` 是重新排版后的 V2 审核成片：前约 2 分钟讲交流痛点与需求，后约 1 分钟讲两个 Skill、交互式对比和 GitHub 仓库。V2 增加了数字卡、对照示例、2×2 边界矩阵、成本条、六项 rubric 和仓库地图。

- 画面：1280×720，30fps，H.264/AAC，时长约 3:01；
- 配音：Edge TTS 的 `zh-CN-XiaoxiaoNeural`，语速 `+10%`；
- `narration-timed.srt`：按实际配音生成的时间轴字幕；
- `subtitles.srt`：按画面段落整理的编辑版字幕；
- [`three-minute-script.md`](three-minute-script.md)：原始口播稿；
- [`three-minute-script-v2.md`](three-minute-script-v2.md)：V2 密集排版分镜；
- [`recording-checklist.md`](recording-checklist.md)：上传前检查项。

配音工具参考：[edge-tts](https://github.com/rany2/edge-tts)。成片文件保留在本地交付包，仓库保存脚本、字幕和可复核的制作说明；上传 B 站前请完整播放一遍并确认字幕、音量和公开链接。
