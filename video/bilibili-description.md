# B 站发布文案

## 标题

让 GPT 少绕路、敢决策、说人话：两个可复核 Skill 的三分钟介绍

## 简介

很多 GPT/Codex 体验的问题，不是模型完全不会做，而是：

- 结论被长前言和复述埋住；
- 普通、可逆的决定反复退回给用户；
- 模型误解后继续客套，修复成本被推回；
- “果断”与“越权”没有清楚分界。

这个视频介绍两个 Skill：

- `decisive-execution`：检查、选择、执行、验证，普通决定由模型承担；
- `human-first-execution`：在决策层上增加结论前置、普通词、低成本 grounding 和直接纠正。
